# MiraTouch · 嵌入式设备远程调试管理平台

MiraTouch 是面向昇腾开发板手势识别系统的远程管理平台，采用 C++ 高性能后端 + Web 前端架构，可在浏览器中远程调节设备参数、管理 SSH 连接并监控运行状态。本项目为大学生创新创业训练计划成果，用于解决多设备批量调试时逐一手动登录效率低下的问题。

## 技术栈

- **后端**：C++，SSH 连接池、异步命令执行、命令批处理、状态缓存
- **通信**：WebSocket 实时推送，毫秒级响应
- **前端**：Web 界面，设备发现、参数配置、状态监控
- **目标设备**：华为昇腾开发板，Linux 环境

## 系统架构

后端维护一个 SSH 连接池，复用已建立的连接避免频繁握手开销；命令执行采用异步任务队列，支持优先级调度与批量命令合并，减少网络通信次数；设备状态通过缓存层统一读取，定期更新并设置失效机制，兼顾响应速度与数据准确性。前端通过 WebSocket 订阅后端状态变化，实现参数调节与运行日志的实时反馈。

## 我负责的部分

主导 C++ 后端性能优化：实现 SSH 连接池的并发控制与超时清理，用互斥锁保护连接获取与释放的原子性；设计异步命令执行的任务队列与线程池，实现优先级调度；实现命令批处理的动态合并策略与失败回退；构建模型状态缓存及过期更新机制。同时参与前端设备分组、状态检测与配置管理界面的改进。

## 关键实现

**SSH 连接池并发控制。** 高并发场景下直接创建连接会带来显著握手开销并存在连接泄漏风险。通过互斥锁保护连接池访问，实现获取与释放的原子操作，配合超时清理自动释放闲置连接，连接建立时间与并发管理能力明显改善。

**异步命令调度。** 同步命令执行会阻塞线程，一次只能处理一个任务。改为任务队列 + 线程池后，重要命令按优先级优先执行，批量命令有序下发，系统可同时管理更多设备。

**状态缓存一致性。** 频繁查询设备状态开销大，但缓存过时又会误导操作。通过定期刷新与状态变更失效相结合的策略，在降低查询开销的同时保证信息准确。
