# MiraTouch

MiraTouch - 专为华为升腾开发板手势识别系统设计的ToB后端管理系统，使用C++编写高性能后端，通过Web界面在浏览器中远程调节参数、管理设备连接和监控性能。

## ✨ 核心特性

- **🔍 自动设备发现** - 扫描局域网，智能列出所有Linux设备
- **🔗 一键SSH连接** - 点击即可建立安全的SSH连接
- **🎮 网页实时控制** - 在浏览器中调整程序参数（置信度、间隔等）
- **📊 实时状态监控** - 实时显示程序输出和运行状态
- **🌐 跨平台访问** - 同一局域网内任何设备都能控制
- **⚡ 实时交互** - WebSocket实现毫秒级响应
- **🔒 安全可靠** - 基于SSH的安全远程连接

## 🎯 主要功能

MiraTouch专为华为升腾开发板手势识别系统设计，提供以下关键功能：

### 设备发现与管理
- 自动扫描局域网内的华为升腾开发板设备
- 实时显示设备状态和连接信息
- 支持多设备管理

### 参数调节与控制
- 通过SSH协议安全地远程执行命令
- 实时参数调整（置信度、检测间隔等）
- 程序启停控制

### 性能监测
- 实时日志输出显示
- 设备连接状态监控
- 程序运行状态跟踪
- 升腾开发板性能指标监测

### 用户界面
- 响应式设计，支持多种设备访问
- 直观的操作界面
- 实时反馈和状态指示
